# Site EuropaFashion

Loja online de perfumes (Luanda e Uíge, Angola). Site estático: funciona no GitHub Pages sem instalar nada.

## Ficheiros
- `index.html`: página da loja
- `estilos.css`: aparência
- `produtos.js`: **lista de produtos e preços** (é aqui que se alteram preços, nomes e descrições)
- `loja.js`: catálogo, pedido e envio pelo WhatsApp
- `imagens/`: logotipo e fotos dos produtos

## Publicar no GitHub Pages
1. Envie todo o conteúdo desta pasta para a raiz do repositório.
2. No GitHub: Settings → Pages → Branch `main`, pasta `/ (root)` → Save.

## Regra de revenda
10 ou mais unidades do mesmo produto: menos 8.000 Kz por unidade (calculado automaticamente no pedido).
